# What is it?
Lofi_news is a news aggregator written using:
* Django 
* [datastar](https://data-star.dev/).
* tailwindCSS
* Vite

## Why should I care?
* you want a more substantial example than the one provided by [datastar-python](https://github.com/starfederation/datastar-python/blob/develop/examples/django/ds/views.py)

* it shows how to use datastar with synchronous responses from django.
